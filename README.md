# агент для работы с кодом

ты описываешь задачу, агент читает файлы, предлагает план, меняет код и запускает тесты.
история и изменения сохраняются в mongodb. изменения можно отменить.

## запуск

нужны java 21 и python 3. команды выполняй из папки проекта.
на mac с процессором apple запусти:

```bash
./scripts/mongo-local start
cp -n .env.example .env
```

на других системах можно запустить базу через `docker compose up -d --wait`,
затем скопировать `.env.example` в `.env` и собрать проект: `./gradlew installDist`.

создай [ключ openrouter](https://openrouter.ai/settings/keys) и вставь в `.env`:

```bash
OPENAI_API_KEY='твой-ключ'
```

адрес сервиса и бесплатная модель уже указаны в примере настроек.
[бесплатный лимит](https://openrouter.ai/pricing) составляет 50 запросов в день.
один запуск агента делает несколько запросов.

```bash
./agent start --task 'исправь расчёт заказа, не меняя тесты' --mode auto
```

агент работает с файлами в `workspace/`. для другой папки добавь `--workspace путь`.
без ключа можно проверить работу с готовыми ответами модели, добавив `--script examples/demo.json`.
сохрани номер запуска, который появится в терминале.

## управление

в командах замени `номер` на номер своего запуска.

| что сделать | команда |
|---|---|
| посмотреть состояние | `./agent status номер` |
| продолжить | `./agent resume номер` |
| посмотреть изменения | `./agent diff номер` |
| отменить изменения | `./agent rollback номер` |
| принять план | `./agent plan номер approve` |
| отклонить план | `./agent plan номер reject` |
| разрешить действие | `./agent action номер approve` |
| запретить действие | `./agent action номер deny` |

для проверки плана до изменений добавь при запуске `--plan`.
в режиме `--mode safe` агент спрашивает разрешение на запись и команды.
в режиме `auto` эти действия выполняются сразу. удаление всегда требует разрешения.

после сбоя начни с `resume`. если агент не знает, завершилось ли действие,
посмотри `./agent recovery-diff номер`. затем выбери:

```bash
./agent recover номер retry --adopt yes
./agent recover номер fail --adopt no
./agent recover номер abort --adopt no
```

`retry` повторяет действие, `fail` сообщает модели об ошибке, `abort` останавливает запуск.
`--adopt yes` означает, что обнаруженные изменения сделал агент, `no` оставляет их твоими.
выбери нужный вариант. команды терминала повторить через `retry` нельзя.

## что где лежит

`src/` содержит код агента, `tests/` его проверки, `workspace/` пример с ошибкой.
`policy.json` задаёт доступные файлы и команды.
`limits.example.json` ограничивает число запросов, действий и размер ответов.
чтобы применить эти лимиты, добавь `--limits limits.example.json`.

агент проверяет каждое действие и сохраняет результат в базе.
задача считается выполненной только после проверки. перед изменением файла сохраняется его копия.
откат остановится, если файл после агента менял кто-то ещё.
во время работы агента не редактируй его рабочую папку.
правила доступа не изолируют запускаемые программы от компьютера. используй учебный проект.

## проверка и остановка

после изменения кода выполни `./gradlew test installDist`.
для проверки с настоящей базой:

```bash
MONGODB_TEST_URI='mongodb://localhost:27017/?replicaSet=rs0&directConnection=true' ./gradlew test --rerun-tasks
```

остановить локальную базу: `./scripts/mongo-local stop`.
данные останутся в `.local/mongo/data`. после перезагрузки снова выполни `start`.
если используешь docker, остановка выполняется командой `docker compose down`.
